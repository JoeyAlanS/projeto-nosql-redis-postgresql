Roteiro: como demonstrar uma diferença e um erro
  1. Clique em Experimentar o CRUD e execute Criar em Ambos. O exemplo usa o ID 9000000010, fora da massa original.
  2. Execute Criar novamente: o console mostra HTTP 409, pois a leitura já existe.
  3. Escolha Redis, operação Atualizar, temperatura 33,50 °C e execute.
  4. Escolha Ambos e Consultar por ID, mantendo o ID do exemplo. O console destaca a diferença no campo temperature_centi.
  5. Escolha Excluir em Ambos para remover o exemplo. Consulte novamente: HTTP 404 significa que a leitura não existe.
As escritas alteram o banco selecionado. Em “Ambos”, PostgreSQL e Redis são executados em sequência, sem transação conjunta ou reversão automática. Os ensaios salvos de 1 e 5 milhões continuam na seção Testes de carga.
